# HCD Portfolio

Dylan Sih's human-centered design research portfolio: needfinding and insights case studies.

A plain static site with no build step.

- `index.html`: page structure and the case study content
- `styles.css`: all styling (colors and the typeface are set at the top)
- `script.js`: project list, card stack scroll effect, and case study routing
- `images/`: project images

To preview locally, open `index.html` in a browser.
